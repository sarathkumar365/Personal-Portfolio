# Personal Portfolio

This portfolio is my working narrative as an engineer.  
It is where I show how I think, how I execute, and what I ship when the stakes are real.

The visual direction is intentional: paper-like, editorial, and slightly old-school in tone.  
I wanted it to feel like reading a crafted letter, not scrolling another template. ✍️

## The Story I’m Telling

I want a visitor to understand three things quickly:

1. Who I am as an engineer.
2. What kind of outcomes I deliver.
3. How I work when problems are messy.

The homepage introduces identity and working style.  
The experience section shows proof and impact.  
The projects section is curated, not crowded, so the strongest work stays visible first.  
The thread across all of it is clarity, credibility, and craft.

## Why This Exists

This is a living portfolio, not a one-time launch.

- It helps recruiters and collaborators see both technical depth and product thinking.
- It reflects the direction I care about most: AI-enabled workflows, reliable systems, and practical automation.
- It gives me a place to keep refining how I present outcomes, not just list projects. 🚀

## Design Theme

The site leans into:

- editorial / typewriter-inspired aesthetics
- measured motion that supports reading
- data-driven content so story updates stay easy
- a calm, intentional tone over flashy UI

## Running It Locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Final Note

I built this to feel personal, deliberate, and trustworthy.  
Every section is trying to answer one core question:  
**Can this engineer take an idea from ambiguity to production with quality?** 🌿
